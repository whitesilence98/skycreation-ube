# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People editing Skyrim characters in a browser-based 3D character editor.

## Product Purpose

Keep the character visible while selecting assets and adjusting character, camera, lighting, and graphics controls.

## Capabilities and Constraints

Preserve all existing features, data flows, selections, import/export, camera gestures, and current disabled states. The responsive HUD replaces fixed 1024×572 transform scaling. Desktop uses docked collapsible rails; narrow viewports use edge drawers. Panels must remain keyboard-accessible, keep local state when hidden, and never reset character selections when switching workspaces.

## Brand Commitments

Preserve the BDO/Skyrim dark-fantasy identity, existing gold line work, glass surfaces, color tokens, font families, and tracking. Text must be at least 10 CSS pixels. Cinzel headers remain part of the stated identity; no replacement font is introduced.

## Product Principles

- The live 3D character is the primary canvas.
- Every existing control stays reachable.
- Panels share available space predictably instead of forcibly closing each other.
- Readability and keyboard access are not traded for density.
